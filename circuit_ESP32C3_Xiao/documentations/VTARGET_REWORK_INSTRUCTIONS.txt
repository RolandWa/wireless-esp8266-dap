--------------------------------------------------------------------------------
1. SYMPTOM
--------------------------------------------------------------------------------
Un-reworked boards show VTarget stuck near 4.19 - 4.21 V and completely
unresponsive to the PWM setpoint. Measured evidence:

    Board    VTarget range measured      Failed points (+/-5%)
    -------  --------------------------  ---------------------
    PCB-01   1338 - 4197 mV  (reworked)  0   / 101   PASS
    PCB-02   4188.6 - 4189.3 mV          93  / 101   FAIL
    PCB-03   4214.1 - 4214.7 mV          94  / 101   FAIL
    PCB-04   4211.1 - 4211.7 mV          94  / 101   FAIL

The DMM range on failing boards varies by less than 1 mV across the whole
0-100% PWM sweep, i.e. the regulator output never moves.

--------------------------------------------------------------------------------
2. ROOT CAUSE
--------------------------------------------------------------------------------
Q1 (YJL2304A) never switches on, so it cannot modulate the AP1117-ADJ feedback
divider, and VTarget stays pinned at its maximum.

R4 and R5 form a divider on the Q1 gate. With the as-fabricated values
(R4 = 39k, R5 = 10k) the maximum achievable gate voltage is:

    Vgs(max) = 3.3 V x R5 / (R4 + R5)
             = 3.3 V x 10k / (39k + 10k)
             = 0.67 V

That is below the YJL2304A gate threshold, so Q1 stays off permanently.

With the reworked values the gate receives nearly the full 3.3 V logic swing,
so Q1 modulates Rds properly and VTarget follows the PWM setpoint.

Note: the ~4.2 V stuck value is consistent with the AP1117-ADJ feedback ratio
set by R3/R1 with Q1 open:

    Vout = 1.25 V x (1 + R3 / R1)
         = 1.25 V x (1 + 27k / 12k)
         = 4.06 V   (nominal; measured 4.19 - 4.21 V)

--------------------------------------------------------------------------------
3. COMPONENTS TO REPLACE
--------------------------------------------------------------------------------
All five parts below differ between the as-fabricated BOM and the current
design. All are 0603 footprints on the PCB.

    Ref  Function                        Fitted (fab)  Required        Note
    ---- ------------------------------- ------------- --------------- ---------
    R4   Q1 gate series resistor         39k           22k (sect. 4)   critical
    R5   Q1 gate pull-down               10k           43k             critical
    C2   PWM filter capacitor            10nF          10uF / 25V      see 5.2
    R1   AP1117 feedback divider, lower  12k           1.2k
    R3   AP1117 feedback divider, upper  27k           2.7k

R4 and R5 are the parts that cause the stuck-output failure. R1 and R3 keep the
same 2.25 ratio but drop the divider impedance by 10x, which gives Q1 usable
control authority over the feedback node.

Old part numbers (for identification of what is currently fitted):
    R1 = 12k   LCSC C114659
    R3 = 27k   LCSC C114614
    R4 = 39k   LCSC C163424
    R5 = 10k   LCSC C98220
    C2 = 10nF  LCSC C9900224280

--------------------------------------------------------------------------------
4. R4 VALUE - RESOLVED (2026-11-25): R4 = 22k
--------------------------------------------------------------------------------
The R4 value was previously in conflict between the KiCad schematic (22k) and
the docs / header comment / bench notes (100 ohm). It is resolved: the KiCad
schematic is the source of truth and its values (R1 = 1.2k, R3 = 2.7k,
R4 = 22k, R5 = 43k, C2 = 10uF/25V) are fitted on all PCBs. The 100 ohm value
in docs/vtarget.md, main/vtarget_pwm.h and the bench notes was wrong and has
been corrected.

History (for reference): 100R was written into the KiCad files in commit
b58231a and then removed again in commit de4efaf, which reverted R4 to 22k.

Consequences of R4 = 22k with C2 = 10uF and R5 = 43k:

    tau = R4 x C2           = 220 ms  (unloaded)
    tau = (R4 || R5) x C2   = 145 ms  (with R5 loading the gate)
    cutoff                  = 0.7 - 1.1 Hz
    Vgs(max) = 3.3 V x 43k / (22k + 43k) = 2.18 V

VTarget therefore needs roughly 0.5 - 1 s to settle after a setpoint change.
Test scripts must wait at least that long per step (see tests/README.md).

--------------------------------------------------------------------------------
5. REWORK NOTES
--------------------------------------------------------------------------------
5.1 Do not change these - they are already correct as fabricated:
        Q1 = YJL2304A       U2 = AP1117-ADJ
        R6 = 100k           R7 = 100k     (VTref sense divider to GPIO2)
        C1 = 10nF           C3 = 10uF     (output capacitor)

5.2 C2 package: the PCB footprint for C2 is 0603. A 10uF / 25V part is not
    commonly available in 0603. Confirm the physical part fits, or fit a larger
    package with flying leads as was done on PCB-01. Record whichever approach
    is used so the design files can be corrected.

5.3 The VTref sense jumper must be fitted for testing. If VTarget is not linked
    to VTref, the on-board ADC reads ~0 mV while the external DMM still reads
    the real voltage. This produced a misleading result on PCB-02 and a 0 V
    reading on PCB-03 during earlier testing.

--------------------------------------------------------------------------------
6. VERIFICATION AFTER REWORK
--------------------------------------------------------------------------------
6.1 Flash the firmware:
        python detect_port.py
        flash_eps.bat COMxx

6.2 Run the VTarget curve test, substituting the correct board serial number:
        python tests/pwm_vtarget_dmm.py --board-id PCB-0x --ip 192.168.137.123

    If the board falls back to its own access point, connect the PC to SSID
    "DAP" and use --ip 192.168.4.1 instead.

6.3 Pass criteria: 101/101 points within +/-5%, and a DMM range spanning
    approximately 1320 - 4200 mV. A range narrower than 50 mV means Q1 is still
    not switching and the rework is incomplete.

6.4 Results are written to:
        tests/test_results/vtarget_PCB-0x_measurements.csv
        tests/test_results/vtarget_PCB-0x_curve.png
        tests/test_results/vtarget_production_summary.csv

6.5 The firmware calibration table (VTARGET_CAL_TABLE in main/vtarget_pwm.c) was
    originally measured on PCB-01. Since 2026-09-08 it is the 25-point median of
    PCB-04/08/09/10 (range 1326-4200 mV). If a reworked board tracks the curve
    but reads consistently high or low, the table needs to be re-measured
    (per-board table) rather than the hardware re-reworked. See
    VTARGET_BATCH_ANALYSIS.md.
