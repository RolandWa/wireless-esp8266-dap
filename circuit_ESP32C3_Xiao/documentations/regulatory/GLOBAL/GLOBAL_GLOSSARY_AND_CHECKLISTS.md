# Global Glossary & Checklists

## Purpose
Reusable definitions and checklists that apply across regions.

## Glossary (selected)
- **Apparatus / product / end item**: the thing actually placed on the market (enclosure, PSU, antennas, etc.).
- **Technical documentation / technical file**: the evidence package supporting conformity claims.
- **Risk assessment**: structured analysis of hazards, severity, probability, and controls.

## Common engineering controls (high-level)
- **Electrical**: limit touch voltages/energies; ensure creepage/clearance; thermal margins.
- **EMC**: grounding strategy, filtering, shielding (as applicable), ESD robustness.
- **Radio**: antenna constraints, power limits, coexistence considerations.

## Common artifacts checklist
- Product description & variants
- Schematics, PCB, BOM
- Label artwork and user manual
- Test plan + test reports
- Traceability for critical components
- Change log / versioning
