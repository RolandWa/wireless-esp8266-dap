# US FCC Overview (starter)

## Purpose
Starter placeholder to capture FCC-related requirements for products that include intentional radio (e.g., Wi‑Fi / BLE modules) and/or unintentional emissions.

This document is intentionally high-level. When you decide the exact US market path (module certified vs end-product certification), expand it with the exact CFR parts, test reports, and labeling/user manual requirements.

## Typical questions to answer
- Is the radio implemented via a **pre-certified module**? If yes, what are the module grant conditions (antenna type, layout, host integration limits)?
- Is the final product an intentional radiator and does it need equipment authorization?
- What are the **labeling** and **user manual statements** required for the host device?

## Evidence to store here (recommended)
- Module FCC ID and grant documents (if using a module).
- Antenna selection rationale + photos.
- EMC emissions test reports for the end product (as applicable).
- Label artwork and user manual compliance statements.
